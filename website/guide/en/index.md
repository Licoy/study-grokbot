## What GrokBot is {#what}

In the words of the official docs, GrokBot gives you **persistent AI teammates called Bots**. Each Bot has a name, a job, and context that builds up over time.

Every Bot works on a **cloud computer** with a browser, a filesystem and a terminal, so it can finish tasks in the tools you actually use instead of just giving advice. You talk to a Bot by typing, dictating or starting a voice chat. The desktop app runs on macOS, Windows and Linux; the mobile app on iPhone and Android.

## How it differs from a chat assistant {#different}

::: props
- Each Bot has a computer: Bots work on a persistent cloud computer and keep going when your laptop is closed. They use connected apps where available and operate the computer otherwise.
- Setup through conversation: Create a Bot, describe the job, and grant access when it asks.
- Bots coordinate: Bots can run in parallel, message each other, share context in group chats, and hand off tasks.
- Learning from demonstration: Walk a Bot through a workflow once; it can save it as a skill and rerun it on a schedule.
- Compounding context: A named Bot keeps its memory, files, browser sessions and preferences across sessions.
:::

## A good first handoff {#first-handoff}

The official advice: start with a **real, multi-tool task that has a clear finish line**. Review the result, correct it, and once the process is stable, turn it into a skill or a Routine.

::: prompt Example: a good first handoff
Your job is [summarising customer feedback every week].
Sources: [a Slack channel] and [the feedback spreadsheet].
Group this week's feedback by theme. For each theme give 3 verbatim quotes with source links, then list the 3 things you think we should fix first.
Only summarise - don't reply to anyone. Show me before doing anything else.
:::
