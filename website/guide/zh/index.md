## GrokBot 是什么 {#what}

按官方文档的说法，GrokBot 提供的是一个个**长期在岗的 AI 队友（Bot）**：每个 Bot 有自己的名字、职责，以及随着使用不断积累的上下文。

每个 Bot 都在一台**云端电脑**上干活，这台电脑有浏览器、文件系统和终端，所以它能直接在你真实使用的工具里把事情做完，而不只是给建议。你可以打字、语音输入或直接语音通话来和它沟通。桌面端支持 macOS、Windows、Linux，手机端支持 iPhone 和 Android。

## 它和普通 AI 助手有什么不同 {#different}

::: props
- 每个 Bot 有一台电脑: Bot 在一台常驻的云端电脑上工作，你合上笔记本它也会继续。能用已连接的应用就用应用，不能就直接操作电脑。
- 通过对话来设置: 新建一个 Bot，告诉它要做什么工作，它需要什么权限时再向你申请。
- Bot 之间会协作: 多个 Bot 可以并行工作、互相发消息、在群聊里共享上下文，并把任务交接给彼此。
- 看你做一遍就会: 你可以带着 Bot 走一遍流程，它能把流程存成“技能”，之后按计划自动重复。
- 上下文越用越多: 一个有名字的 Bot 会在多次会话之间保留记忆、文件、浏览器登录状态和偏好。
:::

## 第一次交接的建议 {#first-handoff}

官方建议：从一个**真实的、要用到多个工具、终点清楚**的任务开始。看完结果、纠正它，等流程稳定了，再把它存成技能或 Routine。

::: prompt 示例：一个好的第一次交接
你的工作是[整理每周的客户反馈]。
来源：[某个 Slack 频道] 和 [反馈表格]。
请把本周的反馈按主题归类，每类给出 3 条原话和出处链接，最后列出你认为最该优先处理的 3 件事。
只整理、不回复任何人。做完先给我看。
:::
