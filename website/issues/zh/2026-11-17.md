## 本期导读 {#intro}

前面十几期讲的都是怎么让 Bot 干活。但很多人用了好几周，设置面板一次都没认真打开过：Routine 的时间莫名其妙差了几个小时，手机在桌面前也照响不误，用量快用完了才发现。

这些问题大多在设置里一两下就能解决。本期把官方文档里的“Settings and notifications”整理成 5 条技巧：把外观和语言调成你顺手的样子、设好时区并导入记忆、管住通知、看懂用量和重置，最后是一组快捷键和深链接。

::: callout 一句话记住本期
Cmd/Ctrl+, 打开设置，Cmd/Ctrl+/ 查看全部快捷键；时区决定 Routine 什么时候跑，通知按 Bot 单独开关，用量随时可以直接问 Bot。
:::

## 可直接上手的 5 条技巧 {#tips}

每条技巧都附了一段示例提示词，把方括号里的内容换成你自己的，就能直接用。

### 技巧一：先把外观和语言调顺手 {#tip1}

打开账号菜单选 **Settings**，或者按 `Cmd/Ctrl+,`。设置里有 **General**、**Computer**、**Vault**、**Usage & Billing** 和 **Updates** 几个面板；具体出现哪些选项取决于你的账号和推送进度，看不到某一项不一定是你操作错了。

::: props
- 深浅色: 在 **Appearance** 里选 **Follow System**、**Light** 或 **Dark**
- 强调色: **Accent** 决定一对一聊天里 Bot 的消息和卡片用每个 Bot 自己的颜色（**Bot color**，默认）还是统一用 **Black**
- 界面语言: **Language** 可以选 **Follow System**，或 20 多种语言之一，包括简体中文和繁体中文；手机上跟随设备的选项叫 **System**，可选语言少一些
- 拼写检查: **Check Spelling While Typing** 默认打开，打字时给拼错的词加下划线
- 麦克风: **System** 一节的 **Microphone** 选择和 Bot 语音对话时用哪个麦克风
- 窗口闪烁: 窗口闪烁或一片空白时，关掉 **Use hardware acceleration**，再选 **Restart Now**；它在 macOS 和 Windows 上默认打开，在 Linux 上默认关闭
:::

单个 Bot 的名字、头像和标签不在设置里：点聊天顶部的 Bot 名字（**View conversation details**）打开详情，点名字或标签就能改，点头像可以换图。个人 Bot 没有描述栏，想改它做什么，直接在聊天里告诉它。

::: prompt
我想把你的定位调整一下。从今天起你主要负责 [一类工作，比如整理每周的读书笔记]。
1. 用一句话复述你的新职责；
2. 列出你现在记得的、和这个新职责冲突的旧习惯；
3. 等我确认后再更新你的记忆。
:::

### 技巧二：设好时区，把别处的记忆导进来 {#tip2}

**Settings → General → Bot** 里有 **Timezone**，Routine 就按这个时区排时间。出差或搬家后发现 Routine 时间不对，先来这里看。这一节还有自动审查的开关和 **Custom Rules**。Grok Bot 自己管理模型选择，所以这里没有模型选择器。

如果你之前在别的 AI 助手那里积累了很多偏好和背景，可以用 **Import** 一节的 **Import Memory to Grok Bot** 搬过来：

::: steps
- 开始导入 | 选 **Start Import**。
- 去问另一个助手 | 把给出的提示词复制到你和另一个 AI 助手的对话里。
- 贴回答案 | 把它的回答贴进第二个框。
- 加入记忆 | 选 **Add to Memory**，内容会交给你的主 Bot，并打开和它的聊天。
:::

::: prompt
我刚把另一个助手那里的记忆导入给你了。请帮我检查一遍：
1. 分成“偏好”“背景”“过时或不确定”三类列出来；
2. 标出你觉得可能已经过时、需要我确认的条目；
3. 在我逐条确认之前，不要删除或改写任何一条。
:::

### 技巧三：管住通知，只在需要你时提醒 {#tip3}

通知按 Bot 单独开关：给某个 Bot 打开 **Notifications**，它完成工作或在等你时，你会收到系统或手机通知。手机上开关在 Bot 的资料页里；桌面端直接让 Bot 自己打开或关掉。群聊没有这种按 Bot 的开关。

::: props
- 在电脑前: 在 macOS 或 Windows 上正在用桌面端时，你自己的 Bot 的通知发到电脑而不是手机；完成的回复不会再推到手机
- 等你回复: Bot 需要你输入时，大约 3 分钟后才会通知手机，除非你先打开那个 Bot、关掉它的 **Notifications** 或把它从侧边栏隐藏
- Linux: Grok Bot 窗口在前台时不弹通知，手机照常收到
- 手机权限: 手机首次运行时会请求通知权限，系统权限和 Bot 的开关都允许才会通知；iPhone 上的推送正在逐步开放
- 侧边栏状态: **Needs attention** 表示有提问、审批或交接在等你，**Unread activity** 表示有新结果；可以在 Bot 的菜单里手动标为已读或未读
- 应用内报错: 出现在输入框上方的 **Notifications** 里，可以逐条关掉或清空；清掉的只是提示，不会撤销已经发生的操作
:::

你的主 Bot 还会主动找你：发现可以替你做的事会先提出来，Gmail 之类的应用登出时会在聊天里告诉你并提出帮你重连。嫌提醒太多，就关掉它的 **Notifications**；这只控制提醒，想彻底关掉这类主动询问需要联系支持。

::: prompt
请帮我整理一下通知：
1. 打开你自己的 Notifications，只在任务完成或需要我处理时提醒我；
2. 列出我所有 Bot 里，哪些现在显示 Needs attention，各自在等什么；
3. 告诉我哪些 Bot 适合关掉通知，理由是什么，先不要替我改别的 Bot。
:::

### 技巧四：看懂用量，用好重置 {#tip4}

**Settings → Usage & Billing** 最多有五个部分，顺序固定：

| 部分 | 能看到什么 |
| --- | --- |
| My plan | 当前套餐和管理按钮，**Billing** 里的 **Manage billing** 管付款方式和发票；企业团队显示 **Managed by your organization** |
| Usage limits | 本周用了多少、什么时候重置；企业成员看到的是消费上限 |
| Grok Bot usage | 用量图，可以 **By Bot**（按 Bot）或 **By source**（按来源）查看 |
| Additional usage | 超出每周用量后的用法：**Credits**、**Buy credits**、**Auto top-up** 等，具体取决于套餐 |
| Resets | 你拥有的重置机会，每条都写着过期日期 |

点 **Use reset** 再点 **Confirm**，每周用量会立刻回到 0%，不用等常规的每周重置；用过一次之后要等一段时间才能再用。达到每周上限时，输入框上方的横幅也会出现 **Use Reset**。没有重置机会时，可能会看到邀请朋友换取一次免费重置的入口。

不想翻设置，也可以在和 Bot 的私聊里直接问：它会告诉你用量现在从哪里算、用了多少、什么时候重置。只有 Bot 的主人能在私聊里问，在群聊等别的地方它会拒绝。出现用量提醒时，点 **Review Usage** 就是让 Bot 帮你看一遍。

::: prompt
请帮我看一下这周的用量：
1. 已经用了多少、什么时候重置；
2. 按 Bot 来看，哪几个用得最多；
3. 给我两三条建议，比如哪些 Routine 可以降低频率。
只给建议，不要自己暂停或修改任何 Routine。
:::

### 技巧五：记住几个快捷键，再用深链接一键开聊 {#tip5}

下面是桌面端最常用的一组快捷键。macOS 上用 `Cmd`，Windows 和 Linux 上用 `Ctrl`：

| 操作 | 快捷键 |
| --- | --- |
| 跳转与搜索面板 | `Cmd/Ctrl+K` |
| 新建 Bot | `Cmd/Ctrl+N` |
| 新建群聊 | `Cmd/Ctrl+Shift+N` |
| 在当前聊天里查找 | `Cmd/Ctrl+F` |
| 切到侧边栏第 1 到 9 个 Bot | `Cmd/Ctrl+1` 到 `Cmd/Ctrl+9` |
| 把选中的文字加进聊天 | `Cmd/Ctrl+L` |
| 在输入框里语音输入 | `Cmd/Ctrl+D` |
| 从任何地方发送 | `Cmd/Ctrl+Enter` |
| 打开连接应用 | `Cmd/Ctrl+Shift+M` |
| 查看全部快捷键 | `Cmd/Ctrl+/` |

想从笔记、快捷指令或别的应用里一键打开某个 Bot 的聊天，可以用深链接：`grokbot://app/v1/prompt?id=<bot-id>&text=<message>`。它会打开那个 Bot 的聊天，把最多 1,000 个字符的文字放进输入框，但不会替你发送；输入框里已经有内容时不会覆盖。不写 `id` 就打开你的主 Bot。Bot 的 ID 是它链接的末尾：点 Bot 名字，选 **Share**，再选 **Copy link**。文字要做编码，比如空格写成 `%20`。

::: prompt
请帮我做一个深链接，用来一键打开和你的聊天：
1. 告诉我怎么拿到你的 Bot ID；
2. 输入框里预先填好这段话：[今天的待办先帮我排一下优先级]；
3. 把文字正确编码，给我完整的链接，并说明它只会填好文字、不会自动发送。
:::

## 几个必须知道的边界 {#limits}

::: steps
- 选项因人而异 | 设置里有哪些部分取决于账号和推送进度，文档里写的选项你不一定都能看到。
- 没有模型选择器 | Grok Bot 自己管理模型选择，设置里没有地方选模型。
- 执行权限按电脑设 | **Execution on this computer** 每台桌面电脑单独设置，默认每条命令都要审批；你的个人自动审查规则则保存在账号里，各设备通用。
- 自动更新会重启 | **Settings → Updates** 里的 **Automatic Updates** 默认打开，会在你锁屏或闲置至少 10 分钟、且 Grok Bot 不忙时安装更新并重启应用；用 `.deb` 或 `.rpm` 安装的 Linux 版通过系统包管理器更新，没有这个开关。
- 用量只在私聊里问 | 只有 Bot 的主人能在私聊里问用量，别指望在群聊里问出来。
:::

## 实战案例：虚构的“写作助手”时区错了 {#case}

一个虚构的场景（并非任何人的真实配置）：一位自由撰稿人配了一个 Bot“写作助手”，每天早上用 Routine 汇总前一天收集的选题。他搬到另一个城市后，汇总总是半夜就到，手机在他坐在电脑前时也一直响。

| 环节 | 做法 | 注意点 |
| --- | --- | --- |
| 查时区 | Settings → General → Bot 的 Timezone 还是旧城市 | Routine 按这里的时区排时间 |
| 改时区 | 改成新城市的时区 | 改完让 Bot 核对每个 Routine 的下次运行时间 |
| 理通知 | 只给写作助手保留 Notifications | 等他回复的提醒约 3 分钟后才到手机 |
| 看用量 | 私聊里问写作助手这周的用量 | 发现一个高频 Routine 占了大头 |
| 降频 | 把那个 Routine 从每小时改成每天两次 | 由他确认后再改 |

### 亮点：十分钟调完，Bot 一直照常工作 {#case-flow}

从发现时间不对到调整完毕，只动了设置和几句对话，没有停用任何 Bot。

::: flow
- 我 | 发现汇总半夜就到 | person
- 写作助手 | 核对时区和运行时间
- 我 | 改时区并调整通知 | person
- 写作助手 | 汇报用量并给出建议
---
- 我 → 写作助手：汇总怎么半夜就来了？先告诉我你按哪个时区排的
- 写作助手 → 我：还是按旧的时区，你在设置里改一下，我再核对一遍
- 我 → 写作助手：改好了，顺便看看这周谁用量最多
- 写作助手 → 我：每小时一次的选题抓取占了大头，建议改成每天两次
:::

后来他让写作助手每周一早上汇报一次上周的用量，提前发现用得多的 Routine。

::: prompt
你是这个“写作助手”。以后请按下面规则：
1. 每周一早上在私聊里汇报上周用量，以及用得最多的三个 Routine；
2. 任何 Routine 的时间、频率要改，先告诉我，等我确认；
3. 需要我处理时才通知我，完成的例行工作不用单独提醒。
先复述规则。
:::

## 社区玩法精选 {#community}

本期整理了几类常见、好上手的用法，供大家参考。都是通用思路，具体内容换成你自己的。

### 一个 Bot 一种颜色 {#c1}

保持 **Accent** 为默认的 **Bot color**，再给每个 Bot 换上不同的头像，一眼就能分清正在和谁说话。

### 换环境先看时区 {#c2}

出差或搬家后的第一件事，是看一眼 **Timezone**，再让 Bot 列出所有 Routine 的下次运行时间。

### 记忆搬家后先体检 {#c3}

用 **Import Memory** 导入之后，马上让主 Bot 把内容分类列出来，过时的条目逐条删掉。

### 通知分级 {#c4}

只给真正需要你介入的 Bot 打开 **Notifications**，其余的看侧边栏的 **Unread activity** 就够了。

### 深链接放进笔记 {#c5}

把常用的几句话做成深链接，放进笔记或快捷指令，点一下就能打开对应 Bot 的聊天并填好文字。
