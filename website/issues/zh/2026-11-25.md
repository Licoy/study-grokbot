## 本期导读 {#intro}

前面二十多期都在讲怎么把 GrokBot 用好，常有新朋友在问更前面的问题：我的订阅里有没有 GrokBot？登录时为什么显示 Grok 或 xAI 的标志？试用会不会自动扣钱？用量用完了又会怎样？

这些问题的答案都在官方文档里，只是分散在好几页。最近官方推出了 The X Subscription，把 Cursor、Grok 和 X 合到一个方案里，旧方案也还在继续，所以更容易让人看糊涂。这一期把开通和计费相关的内容按顺序整理成 5 条技巧，团队和企业的开通方式见[第 20 期](/zh/issues/2026-11-20/)，用量页面和重置见[第 17 期](/zh/issues/2026-11-17/)。

::: callout 一句话记住本期
先确认方案里有没有 GrokBot，再用对的账号登录；试用先拿小任务练手，正式用之前先给超额设上限。
:::

本期的价格、方案名和规则以官方文档为准，会随时调整；做决定之前，请到官方页面再确认一次。

## 可直接上手的 5 条技巧 {#tips}

每条技巧都附了一段示例提示词，把方括号里的内容换成你自己的，就能直接用。付款、升级和取消订阅这类操作，请你本人在官方页面上完成。

### 技巧一：先弄清你的方案里有没有 GrokBot {#tip1}

官方 FAQ 写得很直接：GrokBot 没有单独的订阅，它跟着下面这些方案一起提供：

::: props
- The X Subscription: Premium、Super、Ultra 包含 GrokBot，个人和团队席位都算；Plus 和 Free 不包含
- 旧版 Cursor 方案: Pro、Pro+、Ultra 这几个付费个人方案和自助 Teams 都包含
- 关联 Grok 订阅: 旧版 Cursor 账号可以关联个人的 SuperGrok、SuperGrok Plus、SuperGrok Heavy 或 X Premium+
- Grok Business: 在自助 Grok Business 方案里分到席位，也可以用
- 企业版: 联系你们的 Cursor 客户团队
:::

新用户默认从 The X Subscription 开始。官方定价页列出的月付标价是：Premium 30 美元、Super 100 美元、Ultra 200 美元，不含税；Super 和 Ultra 的每周用量比 Premium 更大。旧方案可以继续用，换不换由你决定。不过要注意，一旦把账号合并到 The X Subscription，这个操作就是永久的，不能撤销，支持团队也没法帮你撤回。

::: prompt
我现在的订阅情况是：[列出你有的订阅，例如 Cursor Pro、SuperGrok]。
请对照官方文档告诉我：
1. 哪一个订阅给了我 GrokBot 的使用资格；
2. 如果换到 The X Subscription，哪些旧订阅会被取消，需要我自己去哪里取消；
3. 有哪些操作是不能撤销的。
只给说明，不要替我做任何购买或更改。
:::

### 技巧二：用对账号登录，必要时关联 Grok 账号 {#tip2}

GrokBot 使用统一的 xAI 登录入口，没有单独的 GrokBot 登录，所以登录页显示 Grok 或 xAI 的标志都正常。在桌面端点 **Sign in**，再到浏览器里完成登录即可。官方特别说明：登录只是验证身份，不会关联或合并你的 X、Grok、Cursor 账号，也不会切换你的方案。

几种常见情况：

::: steps
- 公司用单点登录 | 照常登录，你们在 Cursor 上的单点登录设置同样适用。
- Grok Business 席位 | 在浏览器里选 **Sign in with Grok**，用拿到席位的那个 Grok 账号登录。
- SuperGrok 或 X Premium+ | 在桌面端打开 Get Started with Grok Bot 页面，点 **Link Grok Account**；手机上在开通页面点 **Link Grok Account**，登录 Grok 后点 **Finished Linking? Refresh My Status**。
- 已经能用了 | 打开 **Settings → Usage & billing**，在 **Manage plan** 下找 **Get access with Grok**；只有关联后用量会更多时才会显示。
:::

还有两点要提前知道。第一，GrokBot 需要云端数据存储，如果你的账号开着 Privacy Mode (Legacy)，应用会要求你先换成 Privacy Mode；团队账号由管理员修改。第二，关联是永久的，你自己没法解除或转移；关错了 Cursor 账号，要联系支持，并提供拿到关联的账号和应该关联的账号。

::: prompt
我准备第一次登录 GrokBot，我的使用资格来自 [方案名称]。
请按官方文档列出我该走的登录步骤，标出哪一步需要选择特定账号、
哪一步是永久操作，提醒我在操作前确认哪个邮箱。
:::

### 技巧三：试用额度先拿小任务练手 {#tip3}

部分账号在付费前可以先试用：开通页面出现 **Start trial** 时，点它就行。试用是一笔用量额度，外加 7 天期限，永远不会自动变成付费方案。

官方特别提醒，试用额度按 Bot 实际做了多少工作来扣，算的是步骤和 token，而不是你发了几条消息。所以一个大任务就可能把额度全部用掉，用掉的不会退回。比较稳的做法是：

::: steps
- 范围收窄 | 每次只交一件小事，写清楚到哪一步就算完成。
- 先查用量 | 跑大任务或长任务之前，先在方案页面看一眼还剩多少。
- 别急着上 Routine | 定时任务会反复消耗额度，试用期先手动跑。
:::

免费账号可以在 **Settings → Usage & billing**（手机上是 **Settings → Usage**）点 **Cancel Trial** 提前结束试用，不收费，但剩下的额度会清零，以后也不能再开试用。另外，在 iOS 应用里通过 App Store 开始的免费试用是另一回事：它由 Apple 管理，不提前取消就会转成付费的 Apple 订阅。

::: prompt
我现在在试用期，想先体验一下你能做什么。
请推荐三个用量小、半小时内能做完的任务，每个写清：
要用到哪些应用、大概分几步、做到哪一步算完成。
先不要开始，等我选一个。
:::

### 技巧四：搞懂用量从哪里扣 {#tip4}

不同方案，用量的算法不一样：

::: props
- The X Subscription: GrokBot、Grok 应用和 Cursor 共用一个每周用量池，不是各算各的；超出部分用预付的额度支付；用量在 grok.com/dashboard 的 **Usage** 里查看
- 旧版 Cursor 方案: GrokBot 的用量记在你的 Cursor 账号上，不在 Grok 或 X 那边；在 GrokBot 的 **Settings → Usage & billing** 里查看
- 团队席位: 自助团队方案里每个付费席位有自己的每周用量池，席位之间不共享
:::

旧版 Cursor 账号如果同时有 Cursor 方案和关联的 SuperGrok，两者的用量不会叠加，GrokBot 取每周用量更多的那一个。官方给的对应关系是：Pro、SuperGrok、X Premium+ 同一档，Pro+ 对应 SuperGrok Plus，Ultra 对应 SuperGrok Heavy。两个订阅仍然各自扣费，买了一个不会取消另一个。关联后升级 SuperGrok，每周用量最多要 24 小时才会更新到新档位，不用重新关联。

这也解释了一个常见疑问：SuperGrok 的额度和 GrokBot 的用量对不上，是因为在旧方案里这是两个产品的两套计量。

::: prompt
请告诉我：
1. 我现在的 GrokBot 用量是从哪里算的，在哪里能看到；
2. 这周已经用了多少、什么时候重置；
3. 最近哪几类任务最耗用量。
只汇报，不要暂停或修改任何 Routine。
:::

### 技巧五：给超额用量设一个上限 {#tip5}

每周用量用完之后，可以继续用超额用量，但这部分要另外付钱。不想月底看到意外的账单，就提前设好上限：

::: props
- The X Subscription: 在 grok.com/dashboard/billing 的 **Additional usage credits** 下关掉 Auto Top-up，或者设一个每月的额外用量上限
- 旧版 Cursor 方案: 在 GrokBot 的 **Settings → Usage & billing → On-demand monthly limit** 设上限；也可以在 cursor.com/dashboard 的 **Spending** 下设 **Monthly Limit**
:::

有两点要记住。第一，上限不会在任务中途叫停 Bot，正在跑的任务可能会稍微超出一点。第二，在旧版 Cursor 方案上，如果关掉了超额用量，每周用量用完时 GrokBot 会停下，等每周重置后再继续，重要的 Routine 也会跟着停。

::: prompt
我给超额用量设了每月 [金额] 的上限。
请帮我检查一下我现在所有的 Routine：
按运行频率和每次大概的用量，估一下哪些最可能在用量用完后被卡住，
再建议哪些可以降低频率。只给建议，不要改动任何设置。
:::

## 几个必须知道的边界 {#limits}

::: props
- 合并不可撤销: 合并到 The X Subscription 是永久的，支持团队也撤不回
- 关联不可转移: SuperGrok 或 X Premium+ 一旦关联到某个 Cursor 账号，自己没法解除或转移
- 不能关联的方案: SuperGrok Lite 和 Grok Enterprise 不能关联；Grok Business 席位走 Sign in with Grok，不在方案页面关联
- 邮箱不能改: Cursor 账号的邮箱改不了，想用另一个邮箱只能新建账号
- 退款各走各的: GrokBot 没有单独的订阅，也就没有单独的退款流程；已经用掉的预付额度和超额用量不退，应用商店里的购买由 Apple 或 Google 处理
:::

## 实战案例：虚构的一位独立设计师，从试用到正式开通 {#case}

一个虚构的场景（并非任何人的真实配置）：一位独立设计师想让 Bot 每周整理一次客户反馈。她之前没有订阅过任何相关方案，打算先试用再决定。

::: props
- 起点: 只有一个免费账号
- 目标: 每周一早上收到一份客户反馈汇总
- 顾虑: 不想被自动扣费，也不想月底账单超预算
:::

### 亮点：先试、再买、最后设上限 {#case-flow}

::: steps
- 试用 | 点 Start trial，只让 Bot 手动整理一次上周的反馈，看看效果和用量。
- 选方案 | 效果满意，在官方页面开通 Premium，用同一个账号登录，不再在手机应用里重复购买。
- 设上限 | 开通后先在账单页面设好每月额外用量上限，再把整理反馈设成每周一运行的 Routine。
- 复查 | 第一周结束时，问 Bot 这个 Routine 每次大概用多少，再决定要不要调整频率。
:::

::: prompt
我准备把 [任务，例如每周整理客户反馈] 设成每周运行一次的 Routine。
开始之前，请先手动做一次，做完告诉我这次大概做了多少步、
按这个规模每周运行会不会让我的用量吃紧。确认后再设 Routine。
:::

## 社区玩法精选：开通和控费的小习惯 {#community}

本期整理了几种开通和控费的做法：前三条出自官方文档的说明和建议，后三条是基于官方文档的延伸用法，供你参考。

### 一个方案别买两遍 {#c1}

官方提醒：如果你的方案已经包含 GrokBot，在手机上用同一个账号登录就行，不要再通过 App Store 或 Google Play 另买订阅。手机端的细节见[第 14 期](/zh/issues/2026-11-14/)。

### 登录出错先自查，再带齐信息找支持 {#c2}

官方建议先确认应用是最新版本，从应用里重新走一遍登录流程，有多个账号时确认选对了。还不行就联系支持，带上目标账号的邮箱、完整报错、平台和版本号、截图，以及出错前做过的步骤。

### 升级后等一天再看 {#c3}

官方说明，关联后升级 SuperGrok，每周用量最多要 24 小时才会更新。刚升级就看到用量没变，先别急着重新关联。

### 先设上限，再开 Routine {#c4}

Routine 会在你不在的时候反复运行。先把超额上限设好，再打开定时任务，账单心里有数。

### 一个邮箱对应一个账号 {#c5}

账号邮箱不能改，关联也不能转移。开通前先想好用哪个邮箱，后面能省很多麻烦。

### 每周看一次用量 {#c6}

固定在每周某天问一次 Bot 用量情况，哪个 Bot 或哪个 Routine 用得最多一目了然。
