## 本期导读 {#intro}

开会最累的往往不是讨论本身，而是边听边记、会后整理纪要、再把待办一条条分给大家。Grok Bot 的会议功能就是来接这件事的：Bot 可以加入 Google Meet、Zoom 或 Microsoft Teams 会议，旁听、做记录、在会议聊天里回答问题，散会后把总结和待办发回你们的对话。

按官方文档，会议功能适用于 Team、Enterprise 和 Ultra 套餐，Enterprise 套餐需要管理员先在后台打开。本期从拉 Bot 入会讲起，一直讲到会后怎么用好这份纪要。

::: callout 一句话记住本期
把会议链接发给 Bot、批准卡片、主持人放它进来，它就会旁听记录；散会后，总结和待办会出现在它的对话里。
:::

## 可直接上手的 5 条技巧 {#tips}

每条技巧都附了一段示例提示词，把方括号里的内容换成你自己的，就能直接用。

### 技巧一：三步把 Bot 拉进会议 {#tip1}

官方给出的入会流程很短：

::: steps
- 贴链接 | 把 Google Meet、Zoom 或 Microsoft Teams 的会议链接贴进和 Bot 的对话，请它入会并记录。
- 批准卡片 | Bot 会弹出一张卡片请你批准，点批准即可。
- 主持人放行 | 会议开始后由主持人放 Bot 进来，它的名字显示为“Bot 名（你名字的 Bot）- transcribing”；团队 Bot 显示为“Bot 名（Team Bot）- transcribing”。
:::

如果 Bot 能看你的日历，它还可以自己加入日程上的会议。不知道怎么开口时，打开 Bot 详情：它还没参加过会议的话，Suggested 下面有一个 Add to meeting，会替你起草一句询问入会方法的话。

::: prompt
这是我明天的会议链接：[粘贴会议链接]，会议时间是 [日期和时间]。
请你入会旁听并做记录：
1. 只记录，不要在会议里主动发言；
2. 散会后给我一份总结，重点列出决定事项和待办（谁、做什么、什么时候）；
3. 如果有人在会议聊天里向你要资料，先告诉我是谁要的，不要直接发。
需要我批准的地方请弹卡片给我。
:::

### 技巧二：在 Upcoming 里管好要参加的会议 {#tip2}

打开 Bot 详情，它要参加或正在参加的会议都在 **Upcoming** 里：会显示距离入会的倒计时、周期会议的下一次入会时间，或者正在会中时显示 **Taking notes**。

把鼠标移到你安排的会议上，打开菜单就能看到 Meeting actions：

| 操作 | 作用 | 补充说明 |
| --- | --- | --- |
| Disable Interactivity | 只旁听记录，不在会议里回答 | 这一行显示 Muted；会议还没开始时可用 Enable Interactivity 改回来 |
| Cancel | 取消一场预定的会议 | 适合会议改期或取消时 |
| Quit | 让 Bot 退出正在加入或已在进行的会议 | 已经入会后想恢复互动，需要退出再重新添加 |

::: prompt
请帮我盘点一下你接下来要参加的会议，只汇报、不要改动：
1. 按时间列出每场会议的名称和入会时间；
2. 标出哪些是周期会议；
3. 提醒我哪些会议可能已经不需要你参加了（例如标题里有“已取消”或“改期”）。
我会自己到 Upcoming 里决定取消哪些。
:::

### 技巧三：会中在聊天里点名提问 {#tip3}

会议进行中，在会议聊天里点名 Bot，它就会在聊天里回答。几种特殊情况官方也写清了：

::: props
- Zoom 私聊: 私聊发给 Bot 的消息，它会私下回复
- 会议室设备: 从会议室设备发出的请求算作“会议室”的请求，而不是某个人的
- 被拦下的请求: 有人要了 Bot 没给出的内容时，它会告诉你是谁要的，并问你要不要发
- 凭据: 它不会在会议里分享你的凭据
:::

会上常用的问法是让它即时回顾，例如“刚才关于预算的结论是什么”，比会后翻记录快得多。

::: prompt
今天的会上你会在聊天里被点名提问。请约定好规则：
1. 只回答与本次会议内容有关的问题，回答控制在三句话以内；
2. 涉及我的文件、邮件或账号里的内容，先私下问我，不要直接贴到会议聊天；
3. 有人要你发资料或做事，先记下是谁、要什么，散会后一并告诉我。
复述一遍这些规则。
:::

### 技巧四：散会后把纪要变成行动 {#tip4}

会议结束后，Bot 会在它的对话里发来**总结和待办事项**。如果你有 Pages，较长的报告会放在一个页面里，对话里附上链接。之后你随时可以请它调出某场会议的总结或逐字稿。

还要注意一点：会议使用的是**发起会议那个人**的设置。

拿到纪要只是开始，更省事的是让 Bot 接着把待办整理成你需要的格式，发送、建任务之类的动作照样先经你确认。

::: prompt
请根据我们刚开完的 [会议名称] 的记录，帮我做三件事：
1. 把待办整理成表格：负责人、事项、截止时间，没提到截止时间的标“待定”；
2. 起草一封发给参会者的会后邮件草稿，只放结论和待办，先给我看，不要发送；
3. 列出会上提到但没有结论的问题，方便下次会议跟进。
:::

### 技巧五：团队 Bot 入会，先看团队开关 {#tip5}

团队 Bot 也能参加会议，前提是所在团队允许。Enterprise 套餐里，管理员在团队后台 Grok Bot 页面的 **Bot Capabilities** 下用 **Meetings** 开关统一控制所有人的 Bot：

::: steps
- 开关打开 | 成员的 Bot 可以加入 Google Meet、Zoom 和 Microsoft Teams 会议、转写并汇报。
- 开关关闭 | Bot 不能加入或读取会议；原本预定要参加的 Bot 会告诉你会议功能已不可用。
- 团队 Bot | 只有它自己所在的团队允许会议时才会入会，入会名显示为“Bot 名（Team Bot）- transcribing”。
:::

::: prompt
我们团队想让共用的 [团队 Bot 名称] 参加每周例会。请帮我整理一份给管理员的说明，只起草、不要发送：
1. 说明需要在团队后台打开哪个开关；
2. 说明 Bot 入会后会做什么（旁听、记录、会后总结与待办）；
3. 列出我们打算怎么用：只记录、不在会上发言。
:::

## 几个必须知道的边界 {#limits}

::: steps
- 套餐要求 | 会议功能适用于 Team、Enterprise 和 Ultra 套餐；Enterprise 需管理员先打开。
- 需要主持人放行 | Bot 不会自己闯进会议，入会要由主持人放它进来。
- 设置跟着发起人走 | 会议使用发起这场会议的人的设置。
- 关掉互动要趁早 | 已经入会后想重新打开互动，只能退出再重新添加。
- 不分享凭据 | Bot 不会在会议里分享你的凭据，被拦下的请求会先告诉你。
- 尊重与会者 | 让 Bot 记录前，最好先告知其他与会者会议有 Bot 在转写。
:::

## 实战案例：虚构的“纪要员”怎么包办周会记录 {#case}

延续前几期的虚构阵容（并非任何人的真实配置）：一位小团队负责人每周有三场固定会议，以前总是自己边开边记，会后再花半小时整理。现在她把这件事交给了 Bot“纪要员”。

| 场景 | 做法 | 注意点 |
| --- | --- | --- |
| 周一例会 | 贴链接，请纪要员只记录 | 用 Disable Interactivity 保持安静 |
| 客户沟通会 | 允许它在聊天里回答议程问题 | 涉及内部资料先问她 |
| 临时讨论 | 会中点名问“刚才的结论是什么” | 回答控制在三句话 |
| 散会后 | 收到总结和待办，再要一份邮件草稿 | 邮件她自己确认后再发 |
| 会议改期 | 在 Upcoming 里 Cancel | 重新预定时再贴新链接 |

### 亮点：一条链接，换来一份能直接分派的待办 {#case-flow}

她只做了两件事：开会前贴链接，散会后看结果。

::: flow
- 我 | 贴会议链接并约定规则 | person
- 纪要员 | 主持人放行后入会旁听
- 纪要员 | 记录决定事项与待办
- 纪要员 | 散会后发来总结与待办
- 我 | 确认后分派任务 | person
---
- 我 → 纪要员：入会只记录，有人要资料先告诉我
- 纪要员 → 我：会议已在 Upcoming，开始前会提醒
- 纪要员 → 我：散会，三条决定、五条待办
- 我 → 纪要员：把待办整理成表格，再起草邮件
- 纪要员 → 我：草稿已备好，等你确认后再发
:::

有一次会上有人在聊天里请纪要员“把上周的报价单发一下”，纪要员没有直接贴出来，而是散会后告诉她是谁要的，问她要不要发。

::: prompt
你是这个“纪要员”。以后我发会议链接给你时，请按下面规则处理：
1. 默认只记录，不在会议里发言，除非我说可以互动；
2. 散会后先给我一句话结论，再列决定事项和待办表格；
3. 会上有人向你要任何资料，都先记下是谁、要什么，散会后问我；
4. 需要发邮件或建任务时，先起草给我看。
先复述规则。
:::

## 社区玩法精选 {#community}

本期整理了几类常见、好上手的用法，供大家参考。都是通用思路，具体内容换成你自己的。

### 例会自动纪要 {#c1}

周期会议贴一次链接，之后每次散会都能拿到总结和待办，不用再指定专人记录。

### 只听不说的旁听席 {#c2}

用 Disable Interactivity 让 Bot 安静记录，适合不方便有“第三方发言”的正式会议。

### 会中快速回顾 {#c3}

迟到或走神时，在会议聊天里点名问“刚才讲到哪了”，几句话就能跟上。

### 待办直接进清单 {#c4}

散会后让 Bot 把待办整理进你已连接的任务或笔记应用，先给你看再落地。

### 跨会议追问 {#c5}

隔几天想不起某个决定，直接问 Bot 调出那场会议的总结或逐字稿。
