## 本期导读 {#intro}

前面几期讲的大多是“干活”：整理邮件、开会记录、跑腿下单。其实 Bot 也能动手做图和短片：给一篇文章配一张头图，把一张产品照片变成几秒钟的动态画面，或者做一段能无限循环的短视频。

官方文档在“文件与成果”一页里专门有一节讲生成图片和视频。[第 13 期](/zh/issues/2026-11-13/)只用一小段带过，本期把这一节完整展开，整理成 5 条技巧，再配上社区里几个真实的作品。页面、Library 和附件的用法见第 13 期。

::: callout 一句话记住本期
图片说清主体、风格和比例；视频先选好起点，再定时长和清晰度；图表交给页面，要精确文字的别交给视频。
:::

有一点先说在前面：Bot 只在你开口时才生成图片和视频，不会自己画。它把做好的每张图、每段视频发到对话里；Bot 的电脑休眠时，对话里已经生成的图片也照样能加载。

## 可直接上手的 5 条技巧 {#tips}

每条技巧都附了一段示例提示词，把方括号里的内容换成你自己的，就能直接用。

### 技巧一：用自己的话描述一张图，并说好比例 {#tip1}

官方建议用你自己的话描述想要的画面：主体是什么、什么风格、什么氛围。图片可以是方形、横向或竖向，共五种比例：

- **1:1**：方形，适合头像和方形帖子
- **4:3 和 3:4**：常见的横向和竖向照片比例
- **16:9**：宽屏，适合文章头图和横版封面
- **9:16**：竖屏，适合手机全屏和短视频封面

注意，生图不用来画图表、曲线或表格。需要这类内容时，请 Bot 做成一个[页面](/zh/issues/2026-11-13/)，数字和文字都更准确。

::: prompt
请帮我生成一张图片，用作 [用途，例如：一篇讲周末露营的文章头图]。
画面：[主体，例如：湖边的一顶帐篷和一盏亮着的营灯]。
风格：[风格，例如：温暖的胶片摄影感]，氛围：[氛围，例如：安静、傍晚]。
比例 16:9。先出一张，我看过再决定要不要改。
:::

### 技巧二：把你的照片当成参考图 {#tip2}

想在已有图片的基础上做，就把图发到对话里，并说清楚怎么用。Bot 会把它们当作参考图。

::: steps
- 发图 | 把参考图直接发到对话里，或粘贴进输入框。
- 说用法 | 讲清哪一部分要保留、哪一部分要改，比如“保留构图，换成雪景”。
- 换装试穿 | 官方举的例子：发一张自己的照片，请它看看某套衣服穿在你身上的样子。
- 真实对象 | 涉及知名人物、产品或地点时，Bot 会先去找一张真实照片作为参考。
:::

图片里可以出现真实的人或虚构的人，也包括你自己。不过，如果你只是想看看某个真实的人、地方或产品长什么样，Bot 会去找真实的图片给你，而不是生成一张；找不到的话，它会直说，不会编一张出来。

::: prompt
这是我拍的 [照片内容，例如：工作室的桌面]，请把它当参考图。
保留 [要保留的部分，例如：桌面布局和窗户的位置]，
把 [要改的部分，例如：白天的光线] 改成 [新的样子，例如：夜晚的暖色台灯光]。
比例保持和原图接近，做两个版本让我挑。
:::

### 技巧三：先选好视频的起点，再定规格 {#tip3}

想要视频、动画或短片，直接说就行。官方文档列了视频的四种起点：

::: steps
- 一段描述 | 用文字描述场景，Bot 从零开始做。
- 一张首帧图 | 你发的图会成为视频的第一帧。
- 一首一尾两张图 | 一张做开头、一张做结尾；两张用同一张图，就能做成循环片段。
- 最多 14 张参考图 | 用来说明人物、物品、服装或场景应该长什么样。
:::

另外，你还可以发最多 4 张图，指定它们在片段里的固定时刻出现。规格方面：

::: props
- 时长: 1 到 15 秒，默认 6 秒
- 清晰度: 默认 480p，你要求时可出 720p
- 比例: 1:1、16:9、9:16、4:3、3:4、3:2、2:3；用你的图做的片段默认保持原图比例，除非你另外要求
- 素材: 发给视频用的图必须是 JPEG、PNG 或 WebP，一段视频用到的所有图片加起来约 35 MB 以内
- 文件: 每段视频保存为 MP4
- 耗时: 生成一段视频可能要几分钟
:::

::: prompt
用我发的这张图做一段循环短视频：这张图同时当首帧和尾帧。
画面里让 [要动起来的部分，例如：窗外的雨和杯子上的热气] 慢慢动起来，其他部分保持不动。
比例 9:16，时长 8 秒，清晰度 720p。
:::

### 技巧四：选对适合视频的题材 {#tip4}

官方说明：生成的视频看起来像实拍。所以有的题材很合适，有的最好换个做法。

::: props
- 适合: 真实感的场景、让一张静态照片动起来、让参考图里的角色动起来
- 不适合: 动态图形、标题卡、幻灯片、产品或应用演示、图表
- 也不适合: 任何需要精确文字、精确时间点或品牌素材的内容
:::

要做的东西落在“不适合”里时，换个思路：数据和图表让 Bot 做成页面；要准确的字幕或品牌元素，先生成干净的画面，文字和标志另行处理。还有一点：Bot 把工作交给一个后台任务时，那个任务也能生成图片和视频，做好后同样发回对话里。

::: prompt
我想做一段 [内容，例如：介绍新店开业的短片]。
请先判断：这件事适不适合用生成视频来做？
适合的部分，用生成视频做几段真实感的画面；
需要精确文字、日期或店标的部分，告诉我你建议怎么处理，先别生成。
:::

### 技巧五：查看、保存和找回做好的图和视频 {#tip5}

做好的图片和视频会出现在对话里，之后也能在这个 Bot 的 Library 里找到。

::: steps
- 桌面端查看 | 点图片或视频缩略图全屏打开，再点一下图片可以放大；有多张时用左右方向键或缩略图切换，按 Esc 或点外面关闭。
- 桌面端保存 | 全屏时点顶部的下载按钮；也可以右键图片选 **Copy image** 或 **Save image…**，右键视频选 **Save video…**。
- 批量下载 | 鼠标悬停在消息上点三个点，选 **Download**；一条消息里有多张时选 **Download all**。
- 播放器 | 视频有播放暂停、进度条和倍速菜单（2×、1.5×、1×、0.5×）。
- 手机端 | 点图片全屏，在菜单里选 **Forward** 转发到别的对话、**Share** 或 **Save**；长按图片可选 **Copy Image** 和 **Save to Photos**，长按视频可选 **Save to Photos**。
:::

找以前做的图，打开 Bot 详情进入 Library 标签，或者在桌面端按 `Cmd/Ctrl+K` 搜索，详见[第 26 期](/zh/issues/2026-11-26/)。

::: prompt
把你这周给我生成的图片和视频整理一下：
按用途分组，每组列出文件名、比例、时长（视频）和当时的需求原话，
标出哪些是我最后选用的版本。
:::

## 几个必须知道的边界 {#limits}

::: props
- 只在你要求时生成: Bot 不会自己生成图片和视频
- 真实对象找真图: 想看真实的人、地方或产品长什么样时，Bot 找真实图片，找不到就直说，不会生成一张冒充
- 内容规则: 有些请求会被内容规则拦下，Bot 会告诉你；直接写商标角色、品牌或真人的名字常会被拦，换成自己的话描述再试
- 服务忙: 生图服务繁忙时，Bot 可能请你过一会儿再试
- 账号未开通: Bot 说你的账号用不了图片或视频生成，就是生成功能被关了；在团队里，可能是管理员的模型设置或团队隐私设置导致的，请找管理员
- 图表不走生图: 图表、曲线和表格请做成页面
:::

## 实战案例：虚构的花店店主，一个下午做完一周的配图 {#case}

一个虚构的场景（并非任何人的真实配置）：一位开花店的店主每周要在社交平台发几条帖子，以前都是自己拍照、自己修图。这周她把配图和短片交给了自己的主 Bot。

::: props
- 起点: 几张店里拍的花束照片
- 目标: 三张方形配图，加一段竖屏的循环短片
- 顾虑: 店名和价格必须准确，帖子由她自己发
:::

### 亮点：照片当参考，首尾同帧做循环，文字自己加 {#case-flow}

::: steps
- 配图 | 按技巧二，把花束照片发给 Bot 当参考图，要三张 1:1 的配图，保留花束本身，只换背景。
- 循环短片 | 按技巧三，用最好看的一张同时当首帧和尾帧，做一段 9:16、6 秒的循环片段，让花瓣轻轻晃动。
- 避开文字 | 按技巧四，画面里不放店名和价格，这些由她发帖时自己写在文案里。
- 收尾 | 按技巧五，在对话里一次性 **Download all** 下载，下周再从 Library 里找回来改。
:::

::: prompt
这几张是我店里的花束照片，请当参考图。
1. 做三张 1:1 的配图：保留花束本身，背景分别换成 [背景一]、[背景二]、[背景三]；
2. 用 [其中一张] 同时当首帧和尾帧，做一段 9:16、6 秒的循环短片，只让花瓣轻轻晃动；
3. 画面里不要出现任何文字、店名或价格。
做好后发给我挑，不要发布到任何地方。
:::

## 社区玩法精选：大家用 Bot 做出的画面 {#community}

本期整理了几位用户在 X 上分享的真实作品，以及一条基于官方文档的小技巧。引文为原帖的中文译文，原文请看原帖链接。

### 一句台词，一支音乐短片 {#c1}

::: quote @Frank_SI_Lab | 2026-10-14 | https://x.com/Frank_SI_Lab/status/2110285369186844888
I gave Grok Bot one line of Shakespeare. It came back with a full, animated music video. Grok Bot composed the song (with ElevenLabs Music). Grok Bot created every image (in Canva). Grok Bot brought them to life (with Grok Imagine). Grok Bot cut the video.
---
我给了 Grok Bot 一句莎士比亚的台词，它交回了一整支动画音乐短片。歌是 Grok Bot 用 ElevenLabs Music 写的，每张画面是 Grok Bot 在 Canva 里做的，再由 Grok Bot 用 Grok Imagine 让画面动起来，片子也是 Grok Bot 剪的。
:::

值得学的是分工：作者把作曲、出图、动画和剪辑都交给了 Bot，自己只给了一句台词作为起点。

### 先定一个角色，再铺开 15 个场景 {#c2}

::: quote @luketestsai | 2026-10-20 | https://x.com/luketestsai/status/2112388486296666231
Grok Bot designed one character. Grok Bot generated 15 scenes from that one reference image, timed to the song. Cut the glitchy shots. Close-ups kept giving him an extra leg or a waterfall coming off his chin, so a couple became landscape shots instead.
---
Grok Bot 设计了一个角色，再用这一张参考图生成了 15 个场景，和歌曲的节奏对上。出问题的镜头剪掉：特写镜头总是给他多出一条腿，或者下巴上流下一道瀑布，所以有几个镜头改成了风景镜头。
:::

这和技巧三里“用参考图说明人物长什么样”是同一个思路：先定好一张角色图，后面每个场景都拿它当参考，人物前后就更一致。

### 让 Bot 先替你挑掉废片 {#c3}

::: quote @MikaMilaniX | 2026-10-20 | https://x.com/MikaMilaniX/status/2112270344556052759
Me: Why did you post a photo? I asked for a video. Grok Bot: I tried, but all three videos failed. Me: What was wrong with them? Grok Bot: Extra limbs, melting hands, warped pearls.
---
我：我要的是视频，你怎么发了张照片？Grok Bot：我试了，三段视频都不行。我：哪里不行？Grok Bot：多出来的手脚、融化的手、变形的珍珠。
:::

可以在提示词里明确要求：先自己检查一遍，有明显瑕疵的片段别交，但要告诉你试了几次、问题在哪，需要时再给你看。

### 火柴人动画，用代码画 {#c4}

::: quote @nhaskins | 2026-11-18 | https://x.com/nhaskins/status/2122812028402159861
My Grok Bot video agent wrote a Python rig and drew every frame with OpenCV. The full 3-minute song (4,340 frames) rendered in about 3 minutes across 8 parallel workers. No image model.
---
我的 Grok Bot 视频 Bot 写了一套 Python 程序，用 OpenCV 画出每一帧。整首 3 分钟的歌一共 4,340 帧，用 8 个并行进程大约 3 分钟就渲染完了。没用任何图像模型。
:::

官方说明生成视频不适合动态图形这类内容，这位作者换了条路：让 Bot 写代码一帧一帧地画。线条动画、需要精确控制的画面，可以试试这个思路。

### 同一张图做首尾，得到无缝循环 {#c5}

官方文档写明，首尾两张图用同一张，就能做成循环片段；片段可以是 9:16，正好用作手机竖屏的动态封面或背景。社区里也有人专门分享过这条技巧。
